# Layer 3 Switching – VLANs & Inter-VLAN Routing

A Cisco Packet Tracer project demonstrating VLAN segmentation, Layer 3 switching, and external network connectivity using Cisco 2960 switches, a 3560 Multilayer Switch, and a router.

### Key Features
- VLAN 10 and VLAN 20 configuration
- Trunk links between switches
- Inter-VLAN routing using SVIs
- Router configuration for external connectivity
- Successful ping from PC0 to `8.8.8.8`

### Technologies
Cisco Packet Tracer | CCNA | VLANs | Layer 3 Switching | Inter-VLAN Routing | IPv4 | Routing

### Verification
Verified end-to-end connectivity from PC0 to `8.8.8.8`.
